# Sistema SRS - Sistema de Registro Acadêmico

## Descrição

O Sistema SRS é um projeto desenvolvido para a disciplina de Engenharia de Software, com o objetivo de gerenciar informações acadêmicas e financeiras de uma instituição de ensino.

O sistema permite o cadastro de estudantes e disciplinas, realização de matrículas, registro de notas, consulta de histórico escolar, controle de despesas acadêmicas e geração de balanços financeiros.

---

## Funcionalidades

### Módulo Acadêmico

* Cadastro de estudantes
* Cadastro de disciplinas
* Realização de matrículas
* Registro de notas
* Consulta de histórico escolar
* Listagem de estudantes
* Listagem de disciplinas
* Listagem de matrículas

### Módulo Financeiro

* Registro de despesas acadêmicas
* Listagem de despesas
* Geração de balanço mensal

### Persistência de Dados

* Exportação de estudantes para arquivo CSV
* Importação de estudantes a partir de arquivo CSV
